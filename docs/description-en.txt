ChatGPT Markdown Copier lets you copy entire ChatGPT replies or selected content as Markdown for notes, documents, and knowledge bases. It preserves common formatting and helps reduce manual cleanup of formulas, lists, code, and tables.

Copy an entire reply

The reply action area offers two buttons. Copy reply uses ChatGPT’s original copy action and keeps its output unchanged. Copy Markdown builds on the official output and adjusts inline LaTeX formula delimiters for Markdown, while leaving code regions unchanged.

Copy only what you select

Select content in a reply and copy as usual. The extension converts supported formatting into Markdown, including headings, bold and italic text, links, lists, block quotes, inline code, code blocks, and tables.

When you select text within a single list item, the copied text does not include a list number or bullet. Selections spanning multiple items retain list numbering and nesting.

Mathematical formulas are copied as LaTeX. Selecting part of a formula copies the whole formula, rather than reconstructing only the selected expression.

Tables and Word

A selection within one table cell copies its text without table syntax. Selecting multiple cells or rows produces Markdown table rows. A header and separator are included when the selection includes the table header; selecting only data rows does not add a header. Headerless rows may not render as a table in every Markdown editor.

Selection copy also provides HTML alongside Markdown text. Compatible applications can use it to paste formatted content. Tables include borders and distinct header styling, and formulas are provided as MathML for Microsoft Word. Formulas that cannot be converted fall back to visible LaTeX. The destination application and paste option determine which format is used.

How it works

Whole-reply copying reuses ChatGPT’s official copy action. Selection copying processes a copy of the selected page content without changing the displayed reply or visible selection. Conversion runs locally in the browser and does not send content to an external conversion service.

The extension works on chatgpt.com. Changes to ChatGPT’s interface may affect compatibility.
