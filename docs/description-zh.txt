ChatGPT Markdown Copier 可以将 ChatGPT 的整条回复或选中内容复制为 Markdown，方便保存到笔记、文档和知识库。扩展保留常见格式，减少整理公式、列表、代码和表格时的手工修改。

复制整条回复

回复操作区提供两个按钮。“复制回复”直接使用 ChatGPT 官方复制功能，保留原始输出。“复制 Markdown”在官方结果的基础上，将行内 LaTeX 公式分隔符调整为适合 Markdown 的形式，代码区域保持不变。

只复制选中的内容

在回复中选中需要的内容，像平时一样复制即可。扩展会将支持的格式转换为 Markdown，包括标题、加粗、斜体、链接、列表、引用、行内代码、代码块和表格。

只选中同一个列表项内部的文字时，复制结果不附带序号或项目符号；跨多个列表项选择时，保留列表编号与嵌套层级。

数学公式以 LaTeX 形式复制。即使只选中公式的一部分，也会复制完整公式，目前不会单独还原公式中选中的局部表达式。

表格与 Word 粘贴

只选择一个表格单元格内的内容时，复制其文本，不附带表格语法。选择多个单元格或多行时，输出 Markdown 表格行。选区包含表头时输出表头与分隔行；只选中数据行时不补造表头。无表头的行在部分 Markdown 编辑器中可能无法渲染为表格。

选区复制会同时提供 Markdown 文本与 HTML 内容，兼容的应用可以使用后者粘贴带格式的内容。表格带有边框和可区分的表头样式，公式以 MathML 提供给 Microsoft Word；无法转换的公式保留为可见的 LaTeX。实际采用哪种格式取决于目标应用和粘贴选项。

实现方式

整条回复复制复用 ChatGPT 官方复制功能。选区复制在选中内容的副本上进行格式转换，不修改页面显示的回复或可见选区。转换在浏览器本地完成，不会将内容发送到外部转换服务。

扩展适用于 chatgpt.com。ChatGPT 界面调整可能影响兼容性。
